## ⚙️ Custom Browser Settings & Profiles

### 1. Security & Profile Privacy Strategy
Raw browser profiles (`~/.config/BraveSoftware/...`, `~/.config/google-chrome/...`) contain **sensitive session cookies, decrypted auth tokens, and personal history**. Storing raw profile directories in a Git repository is a major security vulnerability.

The recommended, secure architecture is:
1. **Automated Extension Provisioning**: Use the included `scripts/11-browser-extensions.sh` script, which leverages Chromium's native `External Extensions` mechanism to automatically pre-install all 33 extensions upon browser launch.
2. **Settings, Passwords & Bookmarks**:
   * **Brave**: Use **Brave Sync**. Save your 24-word Sync Chain Phrase in your password manager (e.g. Proton Pass). On a fresh installation, entering the sync phrase immediately restores bookmarks, passwords, and open tabs.
   * **Chrome**: Sign in to your Google Account and enable sync.
3. **Custom Command-Line Flags & User Agents**:
   * Stored in [`dotfiles/.bashrc_custom`](../dotfiles/.bashrc_custom):
     ```bash
     alias brave2='brave-browser --user-agent="Mozilla/5.0 (Linux; Android 13; Pixel 7) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/116.0.0.0 Mobile Safari/537.36"'
     ```
